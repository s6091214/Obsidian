# OverTranslate｜Windows 螢幕即時翻譯工具

> [!info] 官方網站 
> [OverTranslate
> 繁體中文介紹與下載](https://hon-lu.github.io/OverTranslate/zh-TW/)\
> [GitHub 原始碼與版本下載](https://github.com/Hon-Lu/OverTranslate)

## 簡介

OverTranslate 是一款免費、開源的 Windows 螢幕翻譯工具，可以透過 OCR
辨識畫面中的文字，再將翻譯結果顯示在原畫面或獨立對照框中。適合用來翻譯遊戲介面、影片字幕、漫畫、網頁、PDF
與圖片中的文字。

## 主要功能

-   **截圖翻譯**：框選畫面區域，辨識文字並將譯文顯示在畫面上。
-   **即時翻譯**：持續辨識指定的螢幕或視窗區域，畫面文字變動時更新翻譯。
-   **取詞翻譯**：選取文字後快速開啟翻譯小視窗。
-   **替換翻譯**：將選取文字翻譯後直接取代原文，適用於可輸入文字的欄位。
-   **文字翻譯**：輸入或貼上文字翻譯，支援語言互換與文字朗讀。
-   **原文對照**：保留原始畫面，並在獨立對照框顯示譯文。
-   **自訂快捷鍵與外觀**：可調整快捷鍵、淺色／深色主題、譯文字色與底色等設定。

## 支援語言與翻譯服務

-   介面語言：繁體中文、簡體中文、英文、日文、韓文。
-   OCR 可辨識：繁體中文、簡體中文、英文、日文、韓文。
-   內建翻譯服務包括 Google 翻譯、Bing 翻譯、Microsoft
    翻譯、有道翻譯與騰訊翻譯。
-   也可設定 DeepL、OpenAI 相容 API 或本機 AI
    模型；部分自訂服務需要自行提供 API 金鑰或服務位址。

## 遊戲翻譯使用方式

1.  從官方網站下載並安裝 OverTranslate。
2.  開啟程式，將介面與目標翻譯語言設定為繁體中文。
3.  若只想翻譯單一段文字，使用「截圖翻譯」框選文字區域。
4.  若想翻譯持續變動的遊戲介面，使用「即時翻譯」，選擇整個螢幕或指定遊戲視窗。
5.  依畫面內容選擇適合的模式，例如遊戲介面、選單、聊天室或劇情字幕。

> [!tip] 使用建議
> 遊戲選單、技能說明等靜態文字可先用截圖翻譯；對話、字幕或持續變動的介面則可嘗試即時翻譯。OCR
> 與機器翻譯可能出現辨識或翻譯錯誤，重要資訊仍需對照原文。

## 系統需求

-   Windows 10 / 11。
-   即時翻譯的螢幕擷取需要 Windows 11 24H2 或更新版本。
-   即時翻譯的視窗擷取需要 Windows 10 1903 或更新版本。
-   使用內建翻譯服務通常不需要自行申請 API 金鑰；使用 DeepL 或自訂 AI
    模型時，則需依服務要求設定。

## 隱私注意事項

畫面辨識在本機進行，截取的圖片不會上傳；使用線上翻譯服務時，辨識出的文字會傳送至所選服務。若翻譯內容涉及敏感資訊，應留意所使用的翻譯服務與資料處理方式。使用本機
AI 模型時，可讓整個翻譯流程留在自己的電腦上。
