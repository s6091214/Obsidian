
## 🔹 專案概覽
- 技術：Vue 3 + TypeScript + Vite + SPA + Pinia + Tailwind
- 功能：
  1. 首頁熱門電影
  2. 搜尋電影
  3. 電影詳情
  4. 分頁
  5. 單元測試
- TMDB API Key：存於 `.env.local`
- 目標：學習 Vue 3 SPA + API 封裝 + 單元測試
